# mbzuai-coursework

my coursework from MBZUAI, organized by semester and then by course. each assignment/project is in its own folder with a short readme on how to run it.

## fall 2025

| course | folder | what it is |
|---|---|---|
| Intro to AI | [office-category-classification](fall-2025/intro-to-ai/office-category-classification) | multi-class classification on tabular office data, stacked ensemble |
| Python Programming (AI1030) | [market-basket-analysis](fall-2025/python-programming/market-basket-analysis) | grocery basket analysis, frequent item pairs/triples + plots |
| Python Programming (AI1030) | [poi-management-system](fall-2025/python-programming/poi-management-system) | CLI app for managing points of interest and visitors, with spatial queries |

more coming as i go.

## notes

- **what's included:** only assignments and projects. labs, quizzes and exams are left out on purpose.
- **only my code:** the assignment statements, handouts and course-provided datasets are not here, they belong to the course staff. so some things need you to bring your own data to run.
- **group work:** everything here is either my own solo work or group work that all my teammates agreed to make public. there are a few other group projects i didn't publish because i didn't have consent from every teammate, so this isn't everything i worked on.
