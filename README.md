# mbzuai-coursework

my coursework from MBZUAI, organized by semester and then by course. each assignment/project is in its own folder with a short readme on what was asked, what i did, and how to run it.

## notes

- **what's included:** only assignments and projects. labs, quizzes and exams are left out on purpose.
- **only my code:** assignment statements, handouts, course datasets and any starter code / game engines given by the course are not here, they belong to the course staff. so some things need you to bring your own data to run.
- **group work:** everything here is either my own solo work or group work that all my teammates agreed to make public. there are a few other group projects i didn't publish because i didn't have consent from every teammate, so this isn't everything i worked on.
